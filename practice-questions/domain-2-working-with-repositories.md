### Question 1
**Domain**: Domain 2 - Working with GitHub Repositories  
**Topic**: Merge Strategies  
**Difficulty**: Beginner  

A team wants a clean linear history and a single commit per PR. Which merge method should they use?

A. Merge commit  
B. Squash merge  
C. Rebase and merge  
D. Fast-forward only  

<details>
<summary>Answer</summary>

**Correct Answer:** B

**Explanation:** Squash merge combines all commits into one.

**Reference:** https://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/configuring-pull-request-merges
</details>
