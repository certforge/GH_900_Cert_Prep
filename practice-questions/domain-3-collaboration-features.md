# Practice Questions - Domain 3 (Collaboration Features)

### Question 1
**Domain**: Domain 3 - Collaboration Features  
**Topic**: Pull Requests  
**Difficulty**: Beginner  

What is the primary purpose of a pull request?

A. Create a tag  
B. Propose changes for review and merge  
C. Create a release  
D. Store secrets  

<details>
<summary>Answer</summary>

**Correct Answer:** B

**Explanation:** Pull requests are used to propose changes for review and merge.

**Reference:** https://docs.github.com/en/pull-requests
</details>
