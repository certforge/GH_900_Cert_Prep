### Question 1
**Domain**: Domain 7 - Benefits of the GitHub Community  
**Topic**: Community Standards  
**Difficulty**: Beginner

A. LICENSE  
B. CODE_OF_CONDUCT.md  
C. SECURITY.md  
D. README.md  

<details>
<summary>Answer</summary>

**Correct Answer:** B

**Explanation:** CODE_OF_CONDUCT.md defines expected behavior.

</details>
